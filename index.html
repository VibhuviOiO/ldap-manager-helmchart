ldap-manager

A Helm chart for running vibhuvioio/ldap-manager on Kubernetes: the web UI and API that administer one or more OpenLDAP clusters.

This URL is a Helm chart repository. It has no web pages by design — the files here are index.yaml, artifacthub-repo.yml and the packaged charts. Install from it:

helm repo add vibhuvioio-ldap-manager https://VibhuviOiO.github.io/ldap-manager-helmchart
helm repo update
helm install ldap-manager vibhuvioio-ldap-manager/ldap-manager \
  -n directory --create-namespace \
  --set secrets.existingSecret=ldap-manager-secrets
